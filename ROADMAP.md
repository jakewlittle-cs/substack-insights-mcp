# Roadmap

## Near term

- Measurement-age cohorts for fairer post comparisons
- CSV and JSON exports with provenance metadata
- Optional read-only HTTP transport with OAuth for self-hosters
- Additional deterministic topic and format dimensions
- Database migration fixtures across every tagged release

## Later

- Multi-publication workspaces with strict isolation
- Pluggable read-only newsletter sources
- Local dashboards built from the same SQLite facts
- User-defined benchmarks and cohort filters

Publishing and private Substack endpoint automation are intentionally out of scope. If Substack releases an official write API, support can be considered through a separately reviewed adapter.
