# Changelog

All notable changes are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-07

### Added

- Credential-free public RSS ingestion with exact HTML and derived text
- SQLite content ledger with immutable SHA-256-addressed versions
- Timestamped official-MCP metric snapshots with retained raw values
- Deterministic performance calculations, rankings, and correlations
- Twelve MCP tools for archive, analytics, audit, and local Markdown history
- Stdio integration test covering negotiation, snapshot recording, and analysis
- Apache-2.0 licensing and public security/contribution policies
